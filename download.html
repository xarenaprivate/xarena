Android Recommended for you

The native app - built-in update checker, splash screen, everything bundled.

Download the Android app

  1. Tap download, then open the file
  2. Allow install from unknown sources once (standard for direct APKs)

PC / Laptop Recommended for you

Installs as a real desktop app from Chrome or Edge - own window, taskbar icon, works offline for saved pages.

No install button? In Chrome or Edge, click the install icon in the address bar (right side), or Menu → Install XARENA ESPORTS. Firefox and desktop Safari cannot install web apps - the site works fully in them, just without the app window.

iPhone / iPad Recommended for you

Full app with its own home-screen icon - no App Store needed. Honest note: iPhones cannot run Android APK files, and there is no App Store version (yet) - this is the real, complete XARENA app delivered through Safari.

Open the web app
  1. Open xarena.surge.sh in Safari (must be Safari)
  2. Tap the Share button (square with arrow, bottom bar)
  3. Scroll and tap Add to Home Screen → Add
  4. The XARENA icon opens full-screen, just like a store app
